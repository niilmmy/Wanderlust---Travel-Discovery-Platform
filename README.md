# 🌍 Wanderlust - Travel Discovery Platform

Wanderlust is a full-stack travel listing platform where users can explore, create, edit, and manage travel accommodations. It provides a smooth and user-friendly experience for discovering unique places around the world.

## 🚀 Features

- 🔐 User Authentication (Sign Up / Login)
- 🏠 Create, Edit & Delete Listings
- ⭐ Add and Manage Reviews
- 🔍 Search Listings
- 🗂️ Category-based Filtering
- 🗺️ Interactive Map Integration
- 📷 Image Upload with Cloudinary
- 📱 Responsive UI

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** Passport.js
- **Image Storage:** Cloudinary

## 📦 Installation

```bash
npm install
node init/index.js
node app.js
```

Open your browser and visit:

```
http://localhost:8080/listings
```
